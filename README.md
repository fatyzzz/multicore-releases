Этот репозиторий — зеркало релизов. Каждый новый релиз по-прежнему публикуется и сюда, поэтому:

- версии до 1.1.14 продолжают получать обновления отсюда, ничего делать не нужно;
- старые ссылки на скачивание вида `multicore-releases/releases/latest/download/…` работают;
- документы в [`docs/`](docs) и шаблоны Remnawave остаются на своих местах, но актуальные версии — в [основном репозитории](https://github.com/fatyzzz/multicore/tree/main/docs).

Вопросы и баги — в [issues основного репозитория](https://github.com/fatyzzz/multicore/issues).
