This repository is a release mirror. Every new release is still published here as well, so:

- versions before 1.1.14 keep updating from here, with nothing to do on your side;
- old download links like `multicore-releases/releases/latest/download/…` keep working;
- the documents in [`docs/`](docs) and the Remnawave templates stay where they are, but the current versions are in the [main repository](https://github.com/fatyzzz/multicore/tree/main/docs).

Questions and bugs go to the [main repository's issues](https://github.com/fatyzzz/multicore/issues).
